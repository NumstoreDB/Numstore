# Contributing

Contributions are welcome, but I don't have the bandwidth to make the process
easy yet (something I'm working on). File a GitHub issue for bugs, feature
requests or questions. Issues that are easy to pick up are labeled `good first
issue`.

## Before you open a pull request

- Build and test: [docs/developers/reference/make-targets.md](docs/developers/reference/make-targets.md)
- Code style: `.clang-format`, `make format` (a written-up page is planned - see [docs/documentation_plan.md](docs/documentation_plan.md))
