# NAME

resolve_type_ref - resolve a type reference against a numstore type and print the generated type

# SYNOPSIS

**resolve_type_ref** *"TYPE"* *"TYPEREF"*

# DESCRIPTION

**resolve_type_ref** compiles a **numstore**(1) type expression
*TYPE* together with a type-reference expression *TYPEREF*, resolves
*TYPEREF* against *TYPE*, and prints the canonical string form of the
resulting generated type to standard output.

A type reference is itself shaped like a type expression, but its
leaves are dotted paths into *TYPE* (for example `a.a` to reach
member `a` of member `a`) rather than primitive type names. Resolving
a type reference substitutes each path with the part of *TYPE* it
points to, producing a new, concrete type built out of pieces of
*TYPE*. This is useful for checking how a projection or reshaping of
an existing type will resolve before using it elsewhere.

Both *TYPE* and *TYPEREF* are compiled with a private, scratch
allocator that is torn down before the process exits, so no database
state persists across invocations.

# ARGUMENTS

*TYPE*
: A **numstore**(1) type expression - a primitive, **struct { ... }**,
  **union { ... }**, strict array, or nesting of these. See
  **numstore**(1) for the full type system.

*TYPEREF*
: A type-reference expression with the same structural shape as a
  type expression, but with dotted member paths into *TYPE* in place
  of primitive type names.

# OUTPUT

On success, the canonical string form of the type generated by
resolving *TYPEREF* against *TYPE* is written to standard output,
followed by a newline.

On failure, a diagnostic is logged (for a compile or resolution
failure) or written to standard error (if the resulting type string
could not be allocated).

# EXIT STATUS

**EXIT_SUCCESS** (**0**)
: *TYPE* and *TYPEREF* both compiled, resolution succeeded, and the
  generated type's canonical form was printed.

**EXIT_FAILURE** (**1**)
: The argument count was wrong, *TYPE* failed to compile, *TYPEREF*
  failed to compile, resolution failed, or the canonical string form
  could not be allocated.

# EXAMPLES

Resolve a type reference that projects one member and re-embeds
another:

    resolve_type_ref "struct { a u32, b f32 }" "struct { f a, g b }"
