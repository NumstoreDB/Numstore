# v1.5.0

Released 2026-10-29.

Release notes start here. Earlier versions (`v1.0.0` through `v1.4.1`) exist as
git tags but were never written up.

## What you get

Numstore is a single-file ACID database for arrays. At 1.5.0 that means:

- **Arrays as a first-class thing.** A variable has a name, a type and an array
  of elements. Types are primitives, structs, unions and fixed-size arrays,
  nested as deep as you like, and every one of them maps onto a numpy dtype.
- **Seven operations**, not SQL: `create`, `get`, `delete`, `insert`, `write`,
  `read`, `remove`. Ranges use numpy-style `start:stop:step`.
- **Transactions.** One is open at a time, so the schedule is the order they
  commit in and there is no interleaving to reason about.
- **Durability.** `commit()` is the durability point; a crash after it cannot
  take the data back.
- **Python and C.** `pip install pynumstore` gives you numpy arrays back; the C
  library is one static archive and one header.

## Known rough edges at this release

- Concurrent readers and writers are not supported yet. One handle per file.
- Negative strides are rejected.
- The database file is sparse, so `ls -l` overstates it badly. Use `du`.
